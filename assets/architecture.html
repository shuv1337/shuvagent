shuvagent Architecture

Desktop voice-agent for Linux/Hyprland — OpenAI GPT-Realtime-2 full-duplex voice + tool calls

Entry Points & Control

  • • CLI: run, control, start, stop, status commands
  • • ControlServer: Unix socket IPC for session lifecycle
  • • Config: TOML + env file loading with validation
  • • Telemetry: structured JSON OTLP-style events

Voice Session Core

  • • Full-duplex WebSocket to OpenAI GPT-Realtime-2
  • • Streaming PCM16 24kHz audio via PipeWire / sounddevice
  • • Async audio capture, playback, and tool call handling
  • • ShuVoice mic coordination — agent pauses on PTT

Security & Permissions

  • • Default-deny permission gate (Hard Constraint #2)
  • • Tool risk tiers: READ → LOCAL → EXTERNAL → DESTRUCTIVE
  • • 15s TTL + window-focus invalidation + audit trail
  • • User text redaction in telemetry (Constraint #3)

shuvagent • Python 3.12 • uv • pytest • ruff • Linux/Hyprland
