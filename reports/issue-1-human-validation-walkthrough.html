1. Evidence Rules

Do not record sensitive content.

Do not paste transcripts, raw selected text, clipboard contents, audio samples, screenshots containing private text, or API keys into the issue, logs, commit messages, chats, or this report. The safe evidence boundary is control command output, event names, structured reasons, counts, hashes, pass/fail status, and whether audio was heard.

The goal is to prove the live desktop path works while preserving the product privacy contract: no raw user text in logs or telemetry by default.

Allowed Evidence Forbidden Evidence
OK started, OK active, OK stopped, OK idle Full spoken question or model answer
Safe telemetry event names such as audio.capture_chunk Raw transcript text or audio bytes
Structured reasons such as missing_api_key:GOOGLE_API_KEY Actual API key values
Selected-text length/hash prefix The selected text or clipboard text itself
Human statement: "audio was heard" Private desktop screenshots that reveal content

Required closure gates

Gate 1Spoken microphone input through shuvagent run plus shuvagent control start.
Gate 2Audible model speech through the default speaker.
Gate 3Spoken selected-text Q&A using real wl-paste --primary selected text.
Gate 4Gemini Live/Pipecat session using GOOGLE_API_KEY and models/gemini-3.1-flash-live-preview.

4. OpenAI Foreground, Control, Mic, And Speaker Pass

Goal.

Prove that the real foreground process, control socket, microphone capture, model audio response, and speaker playback work together on the target desktop.

Terminal 1: start the foreground app

cd /home/shuv/repos/shuvagent
uv run shuvagent run

Expected evidence:

  • The process stays in the foreground.
  • It prints or logs the control socket path.
  • It does not print API keys or raw transcripts.

Terminal 2: drive the control socket

cd /home/shuv/repos/shuvagent
uv run shuvagent control status
uv run shuvagent control start
uv run shuvagent control status

Expected safe evidence:

OK idle
OK started session=<id>
OK active session=<id>

Human voice prompt

  1. Speak a short, non-sensitive test question into the default microphone.
  2. Wait for model speech.
  3. Confirm whether audio was heard through the default speaker.

Safe evidence to record:

  • audio.capture_chunk was observed.
  • realtime.first_audio_response_latency_ms was observed.
  • audio.playback_chunk was observed.
  • Human result: audio heard: yes/no.

Stop the session

uv run shuvagent control stop
uv run shuvagent control status

Expected evidence:

OK stopped
OK idle

Expected safe telemetry includes agent.session.stopped and, when speech is interrupted, realtime.response_cancel_requested or another structured stop reason.

5. Spoken Selected-Text Q&A

Privacy boundary.

Do not record the selected text. Record only that selection was present, its length or hash prefix if available, tool event names, and whether the spoken answer was relevant.

  1. Select a short, non-sensitive paragraph in any Hyprland window.
  2. Confirm the primary selection path works without printing the selected content:
wl-paste --primary --no-newline | wc -c

Expected evidence: a positive byte count. Do not capture the actual selected text.

  1. Start uv run shuvagent run if it is not already running.
  2. Start a session with uv run shuvagent control start.
  3. Ask by voice: "What does the selected text mean?"
  4. Listen for the answer and stop the session.

Expected safe telemetry and audit evidence:

  • tool.requested for the selected-text read tool.
  • tool.executed for the selected-text read tool.
  • No raw selected text in logs or telemetry.
  • Human result: answer was relevant to the selected text: yes/no.

6. ShuVoice Arbitration

ShuVoice owns the mic during push-to-talk bursts. shuvagent must deny or pause itself rather than fighting for capture.

Pre-start denial while ShuVoice records

shuvoice control start
shuvoice control status
uv run shuvagent control start
uv run shuvagent control status
shuvoice control stop --control-wait-sec 0
shuvoice control status

Expected safe evidence:

OK recording
ERROR start denied: shuvoice-recording
OK idle
OK stopped
OK idle

Mid-session pause and resume

  1. Start a shuvagent session.
  2. Trigger ShuVoice recording during the active session.
  3. Release ShuVoice recording.
  4. Confirm shuvagent resumes without manually restarting the session.

Expected safe telemetry:

  • shuvoice.mic_arbitration action=pause reason=shuvoice-took-mic
  • shuvoice.mic_arbitration action=resume reason=shuvoice-released-mic
  • response.cancel or equivalent cancel request during pause.
  • input_audio_buffer.clear or equivalent input buffer clear during pause.

TTS stop before shuvagent session

If ShuVoice TTS is active, starting shuvagent should request TTS stop before the shuvagent session connects.

Expected safe telemetry: shuvoice.tts_stop_requested ok=true before agent.session.connected.

7. Gemini Live / Pipecat Pass

Credential and model gate.

This pass requires GOOGLE_API_KEY and account/model access for models/gemini-3.1-flash-live-preview. If the key is absent or the model is not enabled for the account, leave this gate blocked with the exact safe failure reason.

Create a temporary Gemini config

tmp_config="$(mktemp /tmp/shuvagent-gemini-XXXX.toml)"
cat >"$tmp_config" <<'TOML'
[realtime]
provider = "gemini"
model = "models/gemini-3.1-flash-live-preview"
api_key_env = "GOOGLE_API_KEY"
voice = "Charon"
session_max_duration_sec = 300
output_token_cap = 800
request_timeout_sec = 10.0
TOML

Run the opt-in live integration smoke

set -a
. ~/.config/shuvagent/local.dev
set +a
SHUVAGENT_RUN_LIVE_GEMINI=1 uv run pytest tests/integration/test_live_gemini.py -q

Expected evidence:

  • The test passes and is not skipped.
  • No API key value is printed.
  • Any failure is recorded only as a safe structured reason.

Run the foreground Gemini session

Terminal 1:

uv run shuvagent --config "$tmp_config" run

Terminal 2:

uv run shuvagent --config "$tmp_config" control start
uv run shuvagent --config "$tmp_config" control status

Speak a short non-sensitive prompt and confirm audible response. Then stop:

uv run shuvagent --config "$tmp_config" control stop
uv run shuvagent --config "$tmp_config" control status

Expected evidence:

  • Session is constructed through Pipecat's Gemini Live service.
  • Mic audio is sent as PCM with explicit sample rate.
  • Model audio is returned and heard.
  • Read-only tools still route through the permission gate.
  • No transcript, selected text, clipboard text, or API key appears in logs.
